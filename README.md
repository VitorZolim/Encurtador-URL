# Encurtador de URL

Projeto desenvolvido para praticar conceitos de arquitetura de software, desenvolvimento de APIs com .NET e interfaces com Blazor.

## Tecnologias utilizadas

- ASP.NET Core Web API
- Entity Framework Core e SQLite
- Blazor Server
- xUnit e FluentAssertions

## Funcionalidades

- Encurtamento de URLs com códigos únicos em Base62.
- Redirecionamento para a URL original.
- Comunicação entre front-end e API via HTTP.
- Proteção de endpoints com Rate Limiting.
- Configuração de CORS.
- Testes de integração.
